# 本机磁盘增量镜像备份

## 备份方式

镜像目标采用独立 Windows 卷上的 `nas-backup` 实目录，例如 `F:\nas-backup`。必须登记实际卷 GUID，禁止使用系统盘、NAS 数据盘、盘符根目录、目录联接或符号链接，不格式化任何物理盘。

每次先创建 C 盘一致性快照：正常暂停写入服务，导出数据库、用户内容、配置及源码，再恢复原来运行的服务。镜像从已完成且校验通过的快照读取，不复制正在运行的数据库目录或整个稀疏镜像。

```text
nas-backup/
├── data/                       # 用户目录，普通文件，可直接读取
├── recovery/
│   ├── database.dump           # PostgreSQL 逻辑导出
│   ├── configuration.tar       # 配置、应用身份与源码，包含敏感凭据
│   ├── manifest.json           # 原一致性快照的归档校验记录
│   └── COMPLETE                # 来源快照标识
└── .garden-zero-backup/         # Windows 隐藏属性的校验、事务和完整历史版本
```

`recovery/manifest.json` 是来源归档的记录，其中 user-content.tar 已展开为 data，不是缺失归档的下载清单。F 盘镜像全部文件的实际哈希记录在隐藏目录的 manifest.json。恢复用户文件可从 data 复制；恢复相册需让 database.dump 与同一次镜像的 data/immich 配套，配置归档需按新主机路径重新核对，不能直接覆盖运行中的实例。

## 增量、删除与校验

- 每次重新枚举并对目标文件进行 SHA-256 内容校验；大小和修改时间相同也不会跨次跳过内容校验。
- 只有新增或内容变化的文件被复制，未变化文件不重写；因此是增量写入，不是每次零成本扫描。
- 来源快照中消失的文件、目录从当前 data 视图移除，但默认保留在完整历史版本中。发起备份时可选择“备份并保留历史”，或“完成后清理全部历史”（包括删除文件与被替换的旧版本）；每日计划和自动重试不额外发起历史清理。C 盘原有一致性快照不受该选项影响。
- 第一次只接受完全空的目标；以后必须匹配上次成功记录。外部改写、额外文件、缺少文件、伪造记录、旧记录回放或卷身份不符均拒绝操作，不自动覆盖或清空“修复”。不要在镜像目录混放文件。
- 清单与事务日志使用 HMAC 签名；密钥保存在 C 盘 secrets/hdd-mirror-key，可信检查点在 C 盘 state/hdd-mirror.json。签名密钥不放入镜像或配置备份，以免目标自证可信。恢复 C 盘后若这两项丢失，不自动接管非空目标，需维护者独立核验。
- 新增/修改内容先写入隐藏暂存区、校验并落盘，然后为上一完整版本创建完整目录快照。文件使用 NTFS 硬链接复用空间，不使用软链接；之后只替换当前视图中的目录项，绝不原地改写与旧版共享的文件。完整历史位于 .garden-zero-backup/history/generation-编号/content，配有签名清单。
- 上一版完整历史尚未保存时，不修改当前备份；当前视图更新期间中断，上一完整版本仍可从历史目录完整读取。断电、磁盘满或拔盘后保留签名事务；重试先校验目标仅处于该事务的旧/新状态。已暂存完整文件直接复用；大文件核对源端与已暂存部分的哈希后从断点继续。前缀不一致只重传暂存文件，不改动上一完整备份。
- 即使明确选择清理历史，也要等新备份全部校验、提交完成才清理；清理中断不影响新提交的完整备份，重试继续清理。未完成事务不是已成功备份。
- 磁盘满时拒绝开始替换和删除；替换过程需要为全部变化文件预留暂存空间。
- 历史数据与当前视图均核对完整哈希；仅允许由已登记历史产生的硬链接，拒绝指向管理范围之外的硬链接。目标目录限制为当前 Windows 用户、SYSTEM 和 Administrators 访问。内容本身不加密；云端适配器仍采用 restic 加密版本仓库。

历史硬链接复用同一文件存储，不防止介质故障或外部程序原地损坏数据。不要手工改写当前备份、历史目录或隐藏事务。备份未完成时应使用上一完整历史目录恢复，避免读取正在更新的当前视图。

## 触发与维护

管理台“立即备份”和“镜像备份”、命令行 backup、每日计划均在新的 C 盘一致性快照成功后更新已配置镜像。数据库停用时跳过，避免把旧快照冒充最新备份。外部镜像失败不删除 C 盘已完成快照，并在管理台显示独立结果。计划启用时，调度器每隔至少五分钟重试失败或落后的镜像，只重用已完成快照，不重复暂停 NAS；重新插盘后可继续未完成事务。

主机只读校验（缺少目标注册时，仅空目标允许初始化元数据）：

```bash
sudo -n python3 -B core/scripts/external-backup.py hdd check
```

完整刷新通过已有主机命令执行：

```bash
bash core/scripts/host-command.sh backup                 # 默认保留历史
bash core/scripts/host-command.sh backup --purge-history # 新备份完整提交后清理全部历史
```

`external-backup.py hdd backup` 是内部适配器入口，只复制已有完成快照；正常使用请选择上面的完整刷新入口。恢复未完成事务需要保留它引用的 C 盘来源快照。不要删除标记、改签名、强行修改检查点或对未知目录执行 rsync --delete。

隔离安全测试：`python3 -B core/tests/verify-mirror.py`，不访问实际配置的目标目录。
