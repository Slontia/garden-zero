# 开发计划与验收范围

## 已实现

- 网页统一管理应用、子功能、日志、目录读写归属及容器资源。
- Immich 相册与可独立关闭的机器学习功能。
- Syncthing 完整本地副本，多设备离线读写；连接向导、进度、冲突副本和历史版本入口。
- 文件浏览、只读 SMB、Git SSH 和私人知识库。
- Tailscale 私人 HTTPS 入口和认证；保存应用启停选择。
- 卷身份校验、受控挂载和干净停机；一致性备份与独立恢复检查。
- data / core / system 分离，Git 仅维护源码、模板及公开文档。

## 后续工作

- 独立磁盘增量镜像：目标身份和签名校验、同步删除、中断续传；物理拔插长期观察另行验收。
- 确定云端备份目标并完成端到端恢复验收。
- 新 Windows 主机从零部署、重启恢复和异机恢复的完整验收。
- 批量媒体、视频、机器学习与多设备同步的长期负载观察。
- 浏览器访问本机 Syncthing 的兼容性和连接体验改进。

## 验收原则

服务健康不等于用户设备配对、外部备份或灾难恢复已经通过。测试脚本和报告必须说明实际范围；缺少验收的功能不声明生产就绪。本机故障原始记录、设备标识和操作会话留在 system 归档，不公开提交。
